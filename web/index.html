How SENTRA works

  1. Existing CCTV streams video (RTSP), no new cameras needed
  2. Edge AI: YOLOv8 detects people and vehicles, ByteTrack follows each one
  3. Rule engine checks zones, time and Away Mode
  4. Guard console gets the alert with a 10-second clip
  5. Guard confirms, then the resident gets a Telegram alert
  6. Every event is logged as evidence for police and JMB

Detection rules

RuleFires when
Perimeter breachperson inside a restricted area (e.g. climbed a gate)
Away Mode breachanyone at a house whose owner is away
Loiteringperson stays at one house too long
Vehicle dwellvehicle stays in a road zone too long
Camera healthcamera offline, frozen or covered

Time limits are shortened in this demo so short clips show each alert (real system: loitering 2 min, vehicle 30 min).

Privacy by design

  • No facial recognition, no identity: only "person" or "vehicle"
  • Alerts judge where and how long, never appearance
  • Video processed on site; only event clips are kept
  • A guard checks every alert before residents are told

What is real in this demo

  • Real SENTRA output: every box, zone, timer, alert, clip and snapshot was produced by the SENTRA code on GitHub
  • Replayed: the camera feeds are recorded clips, played back with the alerts at their original times
  • Simulated here: Confirm / Dismiss and the Telegram message run in your browser only, no message is sent. The working Telegram bot (@SENTRA_Alerts_SDP_bot) is shown in our video
